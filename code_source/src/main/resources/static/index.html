NEXORA Architecture & DevOps Integration

Technical blueprint for packaging this storefront directly into the monolithic JAR.

1. How Spring Boot Serves This Storefront

Spring Boot automatically serves static assets from src/main/resources/static/ at the root path http://localhost:8080/. All files (index.html, styles.css, store.js) are bundled directly into the executable JAR file during Maven compilation.

2. Maven Build & Run Commands

# Clean and compile JAR with Maven:
mvn clean package -DskipTests

3. Spring Security Permitted Static Endpoints

In dev.portfolio.store.config.SecurityConfig, ensure public access to static resources: 

.authorizeHttpRequests(auth -> auth
    .requestMatchers("/", "/index.html", "/*.css", "/*.js", "/assets/**", "/favicon.ico").permitAll()
    .requestMatchers("/api/v1/auth/register", "/api/v1/auth/login").permitAll()
    .requestMatchers(HttpMethod.GET, "/api/v1/products", "/api/v1/products/*").permitAll()
    .requestMatchers("/actuator/health", "/actuator/info", "/actuator/prometheus").permitAll()
    .requestMatchers("/swagger-ui/**", "/swagger-ui.html", "/v3/api-docs/**").permitAll()
    .anyRequest().authenticated())

4. Available Observability Endpoints

GET /actuator/health Readiness & DB checks GET /actuator/prometheus Micrometer metrics GET /swagger-ui.html OpenAPI Specification
